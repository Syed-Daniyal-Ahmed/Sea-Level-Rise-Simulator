How it works: each pixel has a simulated elevation (0–60 m) built from layered noise, biased so land only appears in the top-right and fades toward open ocean bottom-left — a rough coastline shape. Raising the slider runs a flood fill outward from the ocean: a pixel only floods if it's at or below the new sea level and connected to the sea through a chain of equally-low neighbors. A low-lying inland dip with no path to the ocean stays dry, the same way a real basin below sea level (like the Dead Sea) doesn't flood just because it's low. It's the same core idea real tools use (Google's Elevation API, NASA's SRTM data, Climate Central's Surging Seas), just with synthetic terrain instead of a downloaded elevation grid — so it needs no API key and runs entirely in the browser, no network, no GPU. Swap the noise-generated grid for a real heightmap (e.g. grayscale PNG exported from SRTM data for your city) and the same coloring logic works unchanged.
